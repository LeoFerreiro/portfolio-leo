# Lunar Estates — assets

Optimized moon textures for the **Lunar Estates** concept site (a tyso.io studio demo).

| File | Use |
| --- | --- |
| `moon-color-2k.webp` / `moon-color-1k.webp` | Lunar colour / albedo map |
| `moon-bump-2k.webp` / `moon-bump-1k.webp` | Lunar elevation (used as a bump map for crater relief) |

**Source:** NASA Scientific Visualization Studio — *CGI Moon Kit* (LROC colour map + LOLA
elevation). NASA imagery is in the **public domain**. Downsampled and re-encoded to WebP for fast
web delivery.

Served via [jsDelivr](https://www.jsdelivr.com/).
